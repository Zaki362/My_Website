像系统状态一样自然地留在桌面，而不是打断工作的另一块仪表盘。

额度不是设置项。
它是工作节奏的一部分。

当 Codex 成为高频协作工具，隐藏在设置页里的额度会直接影响任务怎么拆、什么时候继续、何时切换工作。Codex Quota 把这段判断压缩成一次自然的桌面扫视。

为 macOS 上的 Codex 重度用户设计。

少一次上下文切换，多保留一点专注。它不替你管理工作，只把真正影响工作的信息放到眼前。

  • 一眼读取，而不是反复查找

    小号组件保留当下最关键的额度值；中号组件补充周限额、重置时间和近期趋势，信息深度随组件尺寸自然变化。

  • 把瞬时额度变成可理解的趋势

    除了剩余百分比，还汇总最近五个已完成自然日的 token 消耗与日均值，帮助你理解真实使用节奏。

  • 本地读取，缩小数据边界

    菜单栏 App 负责读取官方额度接口和本机 Codex 日志，桌面 Widget 只消费脱敏后的本地快照，不直接接触认证文件。

小号 · 快速扫一眼

额度百分比、进度条和状态更新时间保持在第一视觉层，适合放在桌面或小组件抽屉。

中号 · 读懂使用节奏

同时展示五小时额度、每周额度、重置时间、近五天消耗趋势与日均 token。

菜单栏 · 更新与诊断

菜单栏 App 负责抓取、解析和缓存；遇到空数据、过期快照或解析异常时提供可理解的状态。

浅色与深色外观

遵循 macOS WidgetKit 的系统外观，同时保持绿色额度反馈和清晰的数据层级。

从源码安装，三步把额度放到桌面。

当前版本通过 GitHub 源码安装。脚本会构建菜单栏 App 和 Widget 扩展，并放到本机应用目录。

  1. 下载项目

    在 GitHub 克隆 Codex Widget 源码，进入项目目录。发布页与 README 会同步当前版本的要求和变更。

  2. 运行本地安装脚本

    脚本使用完整 Xcode 构建并安装 App。完成后从应用程序中打开 Codex Quota。

  3. 添加桌面组件

    打开 macOS 小组件编辑器，搜索 Codex Quota，选择小号或中号尺寸并放到桌面。

Terminal — install
$ git clone https://github.com/Zaki362/codex-widget.git $ cd codex-widget $ ./scripts/install-local.command
安装命令已准备好

系统要求：macOS 14 或更高版本、完整 Xcode、本机已运行过 Codex 并产生可读取的本地数据。
