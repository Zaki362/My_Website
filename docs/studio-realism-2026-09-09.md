# 数字世界材质与空间精修

## 最终边界

用户在看到 Scheme Engine 参考和生成视觉稿后明确：布局不要大改，不用生成照片替换整个房间。最终方案保留原 Three.js 场景、相机、桌椅/书架/窗/灯/机器人位置、3D 拖动、物品入口、自动日夜、实时时钟和既有 Agent。此前写实底图方案取消，生成稿仅留作参考，不进入网站。

## 参考与设计

参考 https://demos.gsap.com/explore/ 及 https://www.schemeengine.com/ ，2026-09-09 实际浏览。借鉴克制的字级、材料层次和局部暖光，不照搬导航或用整张摄影背景替代交互场景。

最终配色采用石灰、灰绿、胡桃木、炭黑、亚麻与黄铜。只使用项目已有无衬线字体和依赖。

## 实现

- 新增 `studio-materials.ts`：固定种子的本地 Canvas 木纹、灰泥与织物贴图，按材料配置粗糙度和细微凹凸，卸载时统一释放。
- PMREM RoomEnvironment 提供金属和机器人反射；柔化阴影、加接触阴影，调整白天反光强度；书架保留位置并加入三条局部暖灯。
- 桌板/桌腿变薄，椅背增加框架和织物面，人物头部缩小、衣服纹理与头发细节增加；实体中心和导航位置不迁移。
- 原充气椭球叶片改为弯曲薄叶片、细茎和中脉，位置仍在灯旁、桌上、书架和边桌。
- 白天窗景按最新反馈使用 Pexels / Eugene Shirokov 的普通绿树风景 `studio-day-countryside.jpg`，来源与许可记录在同目录 `.source.md`；夜间复用既有 `contact-sky.jpg`，只裁切星空。左墙不挂个人照片，改为细线等高线抽象艺术印刷品，仍无关于入口。照片加载失败时窗景保留渐变，房间仍可探索。
- NPC 保留逐字对话与机器人走跳，UI 改为细边框、柔影；Agent 面板独立作用域，不影响经典主页紫色风格。
- 字体清晰度与夜间可读性收口：墙上欢迎文字改成浅色漆字。
- 桌面机器人、巡游路径和气泡整体稍向左移，边桌略向后退；手机保留原位置。
- 卡片标题使用关于我、我的项目、教育经历、科研经历、工作经历、生活、联系我，英文同步简化。
- 点击未命中入口的房间空白区域关闭卡片；拖动视角和卡片内部点击保留卡片，点击其他物品正常切换。
