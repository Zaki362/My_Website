# AI-native 沉浸式个人工作室

设计记录：2026-09-08。状态：本次画作交互、左上标牌与墙面欢迎语调整已完成本地体验复验；最新本地构建、类型与 lint 检查通过；用户已授权提交并部署。

## 用户目标与页面结构

房间就是整个网站本体。进入 `/ai-native` 后，透视室内场景铺满视口和全部画面边缘，访客置身有人正在电脑前工作的个人空间，通过物品认识 Guohua、探索作品与经历、打开 AI Agent。经典首页 `/` 保持默认入口，左上提供“3D数字世界”入口；新模式独立加载 3D 资源。

页面取消外置 header、intro、footer、导航栏、文字导览和 tour 按钮。欢迎标语“欢迎走进我的数字世界”绘制进墙面真实纹理，返回经典首页通过墙面左上方的“返回经典首页”标牌完成；标牌文案按用户要求固定为“返回经典首页”，上移后让返回操作在空间中更容易辨认。房间采用透视相机和有限角度查看，构图以室内墙面、桌椅、人物、书架和窗景填满画面。以桌面全屏约 1.84:1 为主要版面：视口从 1.35:1 到 1.9:1 时，左右墙面与家具分区逐渐展开，镜头从 49° 调整到 44°，同时稍微转正；物品、焦点与热点一起重排。手机保留近景和平移探索，宽窄屏往返不会累计位移。

正常状态的入口都依附物品：小点或短线提示可探索位置，hover / focus 时显示简短文本，不使用常驻白色标签框。桌面点击物品后，内容以右侧覆盖抽屉呈现；手机使用底部浮层，房间始终留在背景。关闭内容后返回房间并恢复合理焦点。

## 视觉与角色

视觉方向为温暖、安静的真实室内空间。白天采用柔和蓝绿墙面、象牙纸色、自然浅橡木、陶土与旧黄铜；窗外为清浅天蓝。保留夜间原有冷暖光照与暖木色。层次来自空间透视、物品轮廓、材质和光影。墙上文字简短清楚，详细简历保留在内容抽屉中。

盆栽按用户要求放在台灯右边、靠墙的位置，为前景与机器人活动区域留出清晰空间。

用户明确要求保留现有 Agent 的设计。房间机器人延续同款圆润机身、横屏脸、双发光眼、短臂小脚和悬浮光珠，以奶油白 / 鼠尾草绿融入环境。机器人作为现有 Agent 的空间入口，点击即打开原有对话组件。

机器人在房间内走走跳跳，并以传统游戏 NPC 对话风格邀请访客点击聊天。气泡采用纸绿色、硬边轮廓与名字条，显示逐字展开的短句，每 12 秒轮换一句；气泡位置随机器人的三维位置投影更新。气泡本身可点击，打开同一个 `AgentDialog`。遵循系统减少动态效果设置时，机器人与气泡文案保持静态，不播放走跳、逐字动画或定时轮换。

人物、植物与机器人提供轻微环境动态，控件反馈保持简短；遵循 `prefers-reduced-motion`；时钟显示访客当地实时时间，不提供暂停操作。内容抽屉沿用项目字体体系，重点保障正文可读性、焦点可见性和移动端触控面积。

房间、人物、机器人、家具和装饰使用程序几何及代码绘制纹理，不下载或复用参考站图片、模型。本次新增场景没有外部图片或模型素材的授权负担；内容抽屉继续使用网站已有资料与资产。

## AI 行为边界

点击机器人复用现有 `AgentDialog` 和 `/api/agent`。`AgentDialog` 新增可选房间外观：纸色 / 鼠尾草绿的硬边框、名字栏、问题列表和输入区域，夜间切为深绿；仅 `/ai-native` 启用，经典首页的原外观保留。配置可用模型时沿用已有模型问答流程；没有配置模型或模型不可用时，沿用现有站内资料 fallback，不虚构在线模型能力。答案来源、隐私边界、简历请求与异常恢复保持现有机制。房间物品导航与 AI 问答均使用网站现有内容。

NPC 气泡使用本地固定文案，仅承担欢迎与聊天入口提示，不由模型生成，也不代表 Agent 已经开始对话。

## 内部产品 brief 与规则

主要任务是让访客通过房间物品找到本人介绍、作品、经历与联系信息，并与原有 Agent 交流。状态覆盖加载、房间可探索、hover / focus、内容抽屉、AI 对话、昼夜、实时时钟、减少动态效果、WebGL 失败及重试。`rule/navigation-vs-action`：“返回经典首页”标牌使用页面导航语义，打开内容和切灯使用动作语义；`rule/keyboard-complete-flow`：全部物品入口支持 Tab / Enter，Esc 可关闭抽屉或对话，关闭后恢复焦点；`rule/cover-reachable-states`：每个可达状态都提供反馈和退出方式。以上是设计与验收要求，尚不代表验收通过。

工程目标：按路由懒加载 Three.js，限制高 DPI 绘图成本、阴影与动态灯光数量；页面进入后台时暂停渲染，卸载时释放资源。移动视口单独调整透视构图与物品入口，不能依赖 hover 才能使用。失败状态的备用导航与 AI fallback 均需单独验证。

## 白天光照参考与最终方向

用户认为初版白天过亮高饱和，并否定了第一轮偏灰的低饱和试稿，要求查看现成项目的白天光影。参考与实际观察：

- [Sooah’s Room Folio](https://www.sooahs-room-folio.com/)：浏览实际白天场景，借鉴暖木材、彩色物件、柔和日光与带冷色的阴影；其[源码](https://github.com/andrewwoan/sooahs-room-folio/blob/main/src/main.js)采用独立日夜烘焙纹理混合，未复制其模型或纹理。
- [Rowobin 3D Room Portfolio](https://rowobin.github.io/3D-Room-Portfolio/)：[实时灯组](https://github.com/Rowobin/3D-Room-Portfolio/blob/main/main.js#L80-L105)使用暖白主光、冷蓝补光和低强度环境光。借鉴灯光关系，按当前房间比例调节。

最终白天曝光1.1，暖白主光3.0从右上方照入、冷色半球光1.35、左侧冷蓝补光0.8；移除左墙原有大片斜影。恢复自然木材与植物颜色，不再对所有材质统一降饱和；白天地板仅轻微降低橙黄感（78%饱和度），保持木色。材质在交互克隆后保存独立日夜值，重复切换按保存值恢复，夜间保留原材质、贴图、灯光色值、方向与强度。NPC和专属Agent使用象牙纸与淡绿面板，自动时间规则和问答逻辑不变。

本轮最终验收：build、lint与类型通过；正式模式1470×801日→夜→日切换正常，NPC/AI象牙纸色正确；390×844助手无横向溢出且面板完整在视口内；浏览器无JS错误，未发送提问。3098正式预览已启动，截图已更新。

## 入口与实时时钟更新

经典首页入口改为“3D数字世界”（英文“3D World”）。墙上时钟使用本地系统时间驱动同一钟面纹理上的时、分、秒针，每秒校准，回到页面时立即同步；不再承担暂停动画功能，也不显示交互热点。系统减少动态效果与 AI 对话时的环境动画静止仍保留，时钟独立走动；后台停止时钟计时器，卸载时释放。此更新替代前述历史验收中的时钟暂停行为。日夜自动切换规则保持不变。

本轮本地验证：生产构建、lint、类型检查通过；桌面入口文字正确、房间 10 个热点且无暂停入口；时钟持续走动，AI 对话打开及初始系统减少动态效果开启时均继续同步。390×844 首页入口完整且无横向溢出。自动化浏览器动态切换 media 时曾失去响应，重开并在加载前启用减少动态效果后验证通过。本轮用户已确认本地效果并授权推送部署。

时钟视觉修复：后壳与墙面的间距从0.065缩小至0.004，壳体厚度从0.07减为0.04，64段圆周消除明显棱角；三根指针在同一钟面纹理上以共用圆心绘制，避免不同深度的透视偏移和微小自阴影。正式构建、截图与实时时间更新复验通过。
